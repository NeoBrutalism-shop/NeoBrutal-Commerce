System states

No invisible failure modes.

Empty, loading, error, offline, permission and unsupported states share a predictable anatomy so agents do not invent a new pattern for every edge case.

Nothing here yet.Empty state keeps the next meaningful action visible.
Loading ownership…Completion can be announced without turning the skeleton into content.
Payment provider returned an error.Order context remains available for retry.
You appear to be offline.Do not discard cart or ownership state while the network is unavailable.
Permission required.This account can view the license but cannot reassign team seats.
This browser cannot complete this action.Offer a safe alternate path instead of silently hiding the feature.

Ownership lifecycle

States survive the happy path.
